# Dolina Orli

Dokumentacja badawcza, scenariusz, storyboard i materiały produkcyjne filmu dokumentalnego o rzece Orli.

## Cel projektu
Stworzenie rzetelnego filmu dokumentalnego pokazującego Orlę od źródeł do ujścia do Baryczy — przez pryzmat geologii, historii, przyrody, krajobrazu i współczesności.

## Zasady pracy
1. Najpierw kwerenda i weryfikacja źródeł.
2. Następnie rekonstrukcja naukowa i storyboard.
3. Każda scena otrzymuje własną kartę.
4. Każda karta sceny zawiera gotowy prompt do Runway.
5. Animacje geologiczne i historyczne przygotowujemy niezależnie od zdjęć dronowych.
6. Narrację piszemy po przygotowaniu materiału wizualnego i poznaniu rzeczywistych długości ujęć.
7. Materiał dronowy dotyczy współczesnej Orli; w projekcie przyjmujemy maksymalną wysokość 130 m AGL.
8. Przejścia między epokami i skalami mogą być realizowane za pomocą dissolve.

## Struktura
- `00_PROJEKT` — założenia, status i organizacja projektu
- `01_KWERENDY` — dokumentacja badawcza
- `02_SCENARIUSZ` — struktura filmu i rozdziały
- `03_SCENY` — karty scen i prompty Runway
- `04_NARRACJA` — tekst narratora
- `05_ZDJECIA` — plan zdjęciowy
- `06_MAPY` — mapy i materiały kartograficzne
- `07_ZRODLA` — bibliografia i dokumenty źródłowe
- `08_PRODUKCJA` — montaż, sound design i postprodukcja
